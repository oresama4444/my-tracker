# My Tracker

My Tracker is a lightweight web application for tracking personal expenses and incomes and visualizing your financial health through interactive dashboards and analytics.

## Features

- Add, edit, and remove transactions (income & expense)
- Categorize transactions and tag them for filtering
- Recurring transactions and manual adjustments
- Interactive dashboards showing trends, category breakdowns, cash flow, and budget progress
- CSV import/export for backups and migrations

## Why use My Tracker?

My Tracker helps you understand where your money goes, spot trends, and make data-driven budgeting choices. Dashboards provide quick feedback on spending patterns, savings rate, and progress toward financial goals.

## Tech stack

- Frontend: Vite + React + TypeScript
- Styling: CSS (Tailwind optional)

## Getting started

Prerequisites:

- Node.js (16+) and npm or yarn

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Usage

- Log your expenses.
- Log your incomes.
- Use filters (date range, category, tags) on dashboards to analyze specific periods or spending types.
- Export your data as CSV for backups or further analysis.

## Dashboards & Analytics

- Overview: total income, total expenses, net change, and savings rate for the selected period.
- Category Breakdown: donut/treemap showing where money is spent.
- Trends: line charts for income and expenses over time (daily/weekly/monthly).
- Cash Flow: visualize inflows and outflows and detect irregular patterns.
- Budget Tracking: set budgets per category and view progress and overspend alerts.
